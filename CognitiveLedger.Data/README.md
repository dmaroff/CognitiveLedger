# CognitiveLedger.Data

Data-access layer for CognitiveLedger. This project will eventually contain:

- **Database** — SQLite configuration and initialization
- **Database/Migrations** — database migrations
- **Models** — data models
- **Repositories** — repository interfaces and implementations
- **DependencyInjection** — data-layer dependency registration (service collection extensions)

No schema, models, or repository implementations exist yet — those decisions will be made separately.
